## Требования MR2

- [ ] `applyMove(state, move) -> moveResult`
- [ ] Ходы `UP / DOWN / LEFT / RIGHT`

### Правила слияния

```text
[1, 1, empty, empty] -> LEFT -> [2, empty, empty, empty]
[1, 1, 1, empty]     -> LEFT -> [2, 1, empty, empty]
[1, 1, 1, 1]         -> LEFT -> [2, 2, empty, empty]
[2, 2, 4, 4]         -> LEFT -> [4, 8, empty, empty]
```

- [ ] Все четыре примера работают
- [ ] **Одна плитка не объединяется дважды за ход:** `[1, 1, 2, empty] -> [2, 2, ...]`, а не `[4, ...]`
- [ ] **Invalid move не тратит ход** и не создаёт новую плитку
- [ ] После валидного хода появляется ровно одна новая плитка
- [ ] Игра **не** заканчивается при достижении `32%` — доигрываем до лимита ходов
- [ ] Расчёт score
- [ ] Случайность spawn'а отделена от merge-логики
